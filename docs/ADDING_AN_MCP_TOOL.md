# Adding an MCP Tool

1. Implement capability logic independently of MCP.
2. Define a stable tool name.
3. Define explicit input schema.
4. Define explicit output schema where useful.
5. Declare side-effect classification.
6. Add authorization requirements.
7. Register the capability with the plugin/tool registry.
8. Expose it through the MCP adapter.
9. Add discovery tests.
10. Add invocation tests.
11. Add invalid-input tests.
12. Add authorization tests.
13. Document behavior and side effects.
